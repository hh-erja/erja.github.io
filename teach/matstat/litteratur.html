Bra att beställa i god tid
Boken Räkna med risker som jag skrivit själv ligger till grund för samtliga föreläsningarna och räkneövningar. I kapitlen 1 och 3 ingår många förklaringar av och övningar på kursinnehållet.

Det går givetvis inte att läsa kursen utan kurslitteratur. Boken kan rekvireras genom att meddela mig via email att man vill köpa dem eller genom att beställa dem via bokhemsidan Räkna med risker. Detta är bokens hemsida där mycket användbar information finns, t.ex. siffer- eller textmaterial som man kan kopiera och klistra in när man ska lösa vissa övningsuppgifter. Alla böcker som trycks innehåller tryckfel, men bra böcker talar om var tryckfelen finns och det görs för denna bok via Erratalistan. Det kan även hända att man kan hitta dem via fjärrlån från något av universitetsbiblioteken, se Libris om Räkna med risker.
